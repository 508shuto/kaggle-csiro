## 背景

農家は「この牧草地に十分な草があるか」を日々判断する必要がある。牧草バイオマス（利用可能な飼料量）は、放牧のタイミング、休耕の判断、牧草地の生産性維持に直結する。

現在の計測方法には限界がある：
- 手動の刈り取り計測：正確だが時間がかかり、大規模には不可能
- プレートメーター・静電容量メーター：迅速だが条件によって不安定
- リモートセンシング：広域監視が可能だが、種ごとのバイオマス分離ができない

このコンペティションでは、画像からバイオマスを予測するモデルを構築する。成功すれば、農家の意思決定支援、研究者による牧草地追跡の精度向上、持続可能な農業システムの実現に貢献する。

## タスク

牧草地の画像から、放牧管理・飼料管理に重要な5種類のバイオマス成分（グラム）を予測する回帰タスク。

## ターゲット

5つのバイオマス成分を予測する：

| カラム名 | 説明 |
|---------|------|
| Dry_Green_g | 乾燥緑色植物（クローバー除く） |
| Dry_Dead_g | 乾燥枯死物 |
| Dry_Clover_g | 乾燥クローバー |
| GDM_g | 緑色乾物量（Green Dry Matter） |
| Dry_Total_g | 全乾燥バイオマス |

### 物理的関係

ターゲット間には以下の加法的関係がある：

```
GDM_g = Dry_Clover_g + Dry_Green_g
Dry_Total_g = Dry_Clover_g + Dry_Dead_g + Dry_Green_g
```

この制約を予測に活用するかは任意（3変数を予測し、残り2変数を導出する方法もある）。

## 評価指標

重み付き R²（Weighted R²）：

$$
R_{w}^{2} = 1 - \frac{SS_{res}}{SS_{tot}}
$$

ここで：

- $SS_{res} = \sum_{j} w_{j} (y_{j} - \hat{y}_{j})^{2}$（残差平方和）
- $SS_{tot} = \sum_{j} w_{j} (y_{j} - \bar{y}_{w})^{2}$（全平方和）
- $\bar{y}_{w} = \frac{\sum_{j} w_{j} y_{j}}{\sum_{j} w_{j}}$（グローバル重み付き平均）

### 行ごとの重み

| ターゲット | 重み |
|-----------|------|
| Dry_Clover_g | 0.1 |
| Dry_Dead_g | 0.1 |
| Dry_Green_g | 0.1 |
| GDM_g | 0.2 |
| Dry_Total_g | 0.5 |

**注意**: 各ターゲットごとにR²を計算して合計するのではなく、全行に対して単一の重み付きR²を計算する。

## 提出フォーマット

Long format の CSV ファイル（2列のみ）：

| カラム | 説明 |
|--------|------|
| sample_id | `{image_id}__{target_name}` 形式 |
| target | 予測バイオマス値（グラム、float） |

### 有効な target_name

- Dry_Green_g
- Dry_Dead_g
- Dry_Clover_g
- GDM_g
- Dry_Total_g

### 行数

テストセットの各画像につき **5行**（= 画像数 × 5ターゲット）

### 例

```
sample_id,target
ID1001187975__Dry_Green_g,0.0
ID1001187975__Dry_Dead_g,0.0
ID1001187975__Dry_Clover_g,0.0
ID1001187975__GDM_g,0.0
ID1001187975__Dry_Total_g,0.0
ID1001187976__Dry_Green_g,0.0
ID1001187976__Dry_Dead_g,0.0
...
```

## データ概要

### ファイル構成

| ファイル | 説明 |
|---------|------|
| train.csv | 訓練データのメタ情報とターゲット（Long format） |
| test.csv | テストデータのメタ情報（Long format） |
| train/ | 訓練画像（JPEG） |
| test/ | テスト画像（JPEG、スコアリング時に利用可能） |
| sample_submission.csv | 提出ファイルのテンプレート |

### train.csv（Long format）

| カラム | 型 | 説明 |
|--------|-----|------|
| sample_id | str | 訓練サンプルの一意識別子 |
| image_path | str | 画像パス（例: `images/ID1098771283.jpg`） |
| Sampling_Date | str | サンプル採取日 |
| State | str | オーストラリアの州 |
| Species | str | 存在する牧草種（バイオマス順、アンダースコア区切り） |
| Pre_GSHH_NDVI | float | NDVI値（GreenSeeker計測） |
| Height_Ave_cm | float | 平均牧草高さ（落下板計測、cm） |
| target_name | str | ターゲット名（5種類のいずれか） |
| target | float | ターゲット値（グラム） |

行数: 1785（= 画像数 × 5ターゲット）

### test.csv

| カラム | 型 | 説明 |
|--------|-----|------|
| sample_id | str | 予測行の一意識別子（画像×ターゲットごとに1行） |
| image_path | str | 画像パス（例: `test/ID1001187975.jpg`） |
| target_name | str | 予測対象のターゲット名 |

テストセットは **800枚以上** の画像を含む。

**注意**: test.csv には Sampling_Date, State, Species, Pre_GSHH_NDVI, Height_Ave_cm がない。推論時は画像のみが入力となる。

### 画像

| 項目 | 値 |
|------|-----|
| フォーマット | JPEG |
| 元サイズ | 2000 × 1000 |
| リサイズ | 実験ごとに設定 |

### ターゲットの値域

- 下限: 0（非負）
- 上限: なし
- 単位: グラム
