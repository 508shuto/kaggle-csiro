# exp040: CV戦略最適化（3-fold State層化）

## 目的

CV/LB相関を改善するため、CV戦略を最適化する。現行の5-fold Species層化からState欠落問題を解消し、Tas/Vic分布を均等化する。

## ベース

exp028（DINOv3 Large 512px, Frozen backbone）

## 設定

### CV戦略の変更

| 項目 | exp028 | exp040 |
|------|--------|--------|
| Fold数 | 5 | **3** |
| 層化 | species | **state** |
| グループ | `sampling_date` | `sampling_date + "_" + state` |
| Seed | 42 | **1129** |

### seed 1129の特性

```
サンプル数: [126, 119, 112]  (Range=14)

State分布:
  Tas: [53, 47, 38]  (Std=7.5) ← 最も均等
  Vic: [40, 34, 38]  (Std=3.1) ← 最も均等
  NSW: [21, 26, 28]
  WA:  [12, 12, 8]

重要Species（全foldに含有）:
  Fescue:  [11, 9, 8]
  Lucerne: [10, 7, 5]
```

### モデル設定（exp028から継承）

- モデル: vit_large_patch16_dinov3.lvd1689m
- 画像サイズ: 512x512
- Backbone: Frozen
- 学習率: 1e-3
- エポック数: 100
- EMA: decay 0.995
