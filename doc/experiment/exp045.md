# exp045: Qwen3-VL-2B Feature Extraction Regression

## 目的
Qwen3-VL-2Bの視覚エンコーダーを使用して特徴量抽出し、バイオマス回帰を行う。VLMの視覚エンコーダーがDINOv3より良い画像表現を持つかを検証。

## 設定
- モデル: Qwen/Qwen3-VL-2B-Instruct（視覚エンコーダーのみ使用）
- 特徴量: DeepStack方式の多層ViT特徴量
- 学習戦略: Vision encoder frozen + Head学習
- CV: 3-fold, State stratification（exp043/044と同様）
- 物理制約: 3変数予測 → 残り2変数導出

## ベース
- パイプライン: exp044
- CV戦略: exp043
