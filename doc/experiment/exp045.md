# exp045: Qwen3-VL-Embedding-2B Feature Extraction Regression

## 目的
Qwen3-VL-Embedding-2Bを使用して画像から2048次元の特徴量を抽出し、バイオマス回帰を行う。VLMベースのEmbeddingがDINOv3より良い画像表現を持つかを検証。

## 設定
- モデル: Qwen/Qwen3-VL-Embedding-2B（凍結）
- Embedding次元: 2048
- 特徴抽出方式: DeepStack（レイヤー[8,16,24]融合）+ EOSトークン
- 学習戦略: Embedding frozen + Head学習
- Head: MLP (2048 → 512 → 3)
- CV: 3-fold, State stratification
- Loss: SmoothL1Loss
- lr: 1e-3（Headのみ）
- batch_size: 32
- epochs: 30
- 物理制約: 3変数予測 → 残り2変数導出

## ベース
- パイプライン: exp044
- CV戦略: exp043
