# exp042: Main Species CV戦略

## 目的

exp040のCV戦略を改善し、全Main Speciesが全Foldに存在する分割を実現する。

## ベース

exp040（DINOv3 Large 512px, Frozen backbone, 3-fold）

## 設定

### CV戦略の変更

| 項目 | exp040 | exp042 |
|------|--------|--------|
| Fold数 | 3 | 3 |
| グループ | date+state | **date+state+main_species** |
| 層化 | state | **state+main_species** |
| Seed | 1129 | **8635** |
