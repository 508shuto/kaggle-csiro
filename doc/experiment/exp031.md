# exp031: Augmentation簡素化

## 目的
Augmentationを3種のみに簡素化し、過度なAugmentationによる精度低下を防ぐ。

## 背景
チームメンバーの知見:
- 採用: HorizontalFlip, VerticalFlip, RandomBrightnessContrast のみ
- 不採用: RandomShadow, Mixup など（精度向上なし）

現状の設定では多数のAugmentation（elastic, gamma, gaussian_noise, blur, mixup等）を適用しており、これが過学習防止より害が大きい可能性。

## 設定
- ベース: exp030（Tile + MHA統合）
- モデル: vit_large_patch16_dinov3.lvd1689m
- Backbone凍結: true
- 画像サイズ: 512×512
- Tile処理: 2×2グリッド + GeM Pooling
- MHA統合: あり

### Augmentation変更
| 項目 | Before | After |
|------|--------|-------|
| HorizontalFlip | 0.5 | 0.5 |
| VerticalFlip | 0.5 | 0.5 |
| BrightnessContrast | true | true |
| Rotation | 20 | **0** |
| Shift/Scale | 0.1/0.2 | **0** |
| ElasticTransform | true | **false** |
| GammaTransform | true | **false** |
| GaussianNoise | true | **false** |
| Blur | true | **false** |
| Mixup | enabled | **disabled** |
