# exp029: Tile処理追加 (2×2 + GeM Pooling)

## 目的
チームメンバーの結果を追試。Tile処理（2×2グリッド + GeM Pooling）による精度向上を検証する。

## 背景
- exp028 (Tileなし): CV 0.68
- チームメンバー (Tile追加): CV 0.78037 (+0.10)

## 設定
- モデル: vit_large_patch16_dinov3.lvd1689m
- Backbone凍結: true（Headのみ学習）
- 画像サイズ: 512×512
- **Tile処理**: 2×2グリッド（各タイル256×256）+ GeM Pooling
- 学習率: 1e-3
- エポック数: 100
- Fold数: 5
- EMA: decay 0.995
- 補助ロス: NDVI + 高さ (weight: 0.1)

### Tile処理詳細
```
入力画像 (B, 3, 512, 512)
    ↓
2×2グリッド分割（重なりなし）
    ↓
4タイル → backbone → 4特徴ベクトル (B, 4, 1024)
    ↓
GeM Pooling (p=3.0, learnable) → (B, 1024)
    ↓
Head → 予測
```

## 考察
- 期待(CV 0.78)に対して実際は0.6606で未達
- Tile処理+GeM Poolingが期待通り機能しなかった可能性
- Fold2が特に低い（0.54）、exp028(0.59)より悪化
- exp028より分散が大きい（0.067 vs 0.061）
- 仮説: タイル分割による文脈情報の損失？
