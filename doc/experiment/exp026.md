# exp026: DINOv2フリーズ + 回帰ヘッドのみ学習

## 目的
exp025をベースに、DINOv2のbackboneを特徴量抽出器としてフリーズし、回帰ヘッドのみを学習する実験。Backboneをフリーズすることで、学習の高速化とメモリ使用量の削減を目指す。

## 設定
- モデル: DINOv2 ViT-B/14 (vit_base_patch14_dinov2.lvd142m)
- 特徴量抽出: Backboneフリーズ（requires_grad=False）
- 主要ハイパーパラメータ:
  - Loss: WeightedSmoothL1Loss（重み: `[0.1, 0.1, 0.1, 0.2, 0.5]`）
  - Aux Loss: MSE（weight: 0.1）
  - Optimizer: AdamW (lr: 1e-3, weight_decay: 1e-2)  ※ヘッドのみ学習のためlr上げ
  - Scheduler: Cosine
  - Batch size: 16 (train), 32 (valid)
  - Epochs: 50（フリーズ時は収束が早いためepoch数削減）
  - Image size: 518（DINOv2推奨サイズ）
  - Mixup: enabled (alpha: 0.2, prob: 0.5)
- 変更点:
  - **DINOv2をbackboneとして使用**: ConvNeXt Tiny → DINOv2 ViT-B/14
  - **Backboneフリーズ**: `requires_grad_(False)`でbackbone全体をフリーズ
  - **回帰ヘッドのみ学習**: head, aux_headのパラメータのみoptimizerに渡す
  - **画像サイズ変更**: 256 → 518（DINOv2の推奨サイズ）
