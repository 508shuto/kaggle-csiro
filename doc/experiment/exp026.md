# exp026: DINOv3フリーズ + 回帰ヘッドのみ学習

## 目的
exp025をベースに、DINOv3のbackboneを特徴量抽出器としてフリーズし、回帰ヘッドのみを学習する実験。Backboneをフリーズすることで、学習の高速化とメモリ使用量の削減を目指す。

## 設定
- モデル: DINOv3 ViT-B/16 (vit_base_patch16_dinov3)
- 特徴量抽出: Backboneフリーズ（requires_grad=False）
- 主要ハイパーパラメータ:
  - Loss: WeightedSmoothL1Loss（重み: `[0.1, 0.1, 0.1, 0.2, 0.5]`）
  - Aux Loss: MSE（weight: 0.1）
  - Optimizer: AdamW (lr: 1e-3, weight_decay: 1e-2)  ※ヘッドのみ学習のためlr上げ
  - Scheduler: Cosine
  - Batch size: 16 (train), 32 (valid)
  - Epochs: 100
  - Image size: 224（DINOv3標準サイズ）
  - Mixup: enabled (alpha: 0.2, prob: 0.5)
  - Checkpoint: last epochのみ保存（`fold{N}_epoch{NN}.ckpt`）
- 変更点:
  - **DINOv3をbackboneとして使用**: ConvNeXt Tiny → DINOv3 ViT-B/16
  - **Backboneフリーズ**: `requires_grad_(False)`でbackbone全体をフリーズ
  - **回帰ヘッドのみ学習**: head, aux_headのパラメータのみoptimizerに渡す
  - **画像サイズ**: 224（DINOv3の標準サイズ）
