# exp037: LoRA Fine-tuning

## 目的
exp028のDINOv2バックボーンにLoRAを適用し、Attention層を効率的にファインチューニングして精度向上を目指す

## 設計

### アーキテクチャ
- **Backbone**: facebook/dinov2-large (HF Transformers)
- **LoRA**: peftライブラリによる適用
- **入力解像度**: 512x512
- **Head**: exp028と同一構造

### モデル構造
```
CSIROModel
├── Backbone: DINOv2-Large + LoRA adapters
│   └── LoRA適用レイヤー: 18-23 (最後の6層)
├── Head: Linear layers
└── 物理制約: GDM = Clover + Green, Total = Clover + Dead + Green
```

### LoRA設定
| パラメータ | 値 |
|-----------|-----|
| r (rank) | 8 |
| alpha | 16 |
| dropout | 0.1 |
| target_modules | query, key, value, dense |
| layers_to_transform | [18, 19, 20, 21, 22, 23] |

### パラメータ数
| 種類 | パラメータ数 |
|------|------------|
| LoRA (trainable) | 393,280 |
| Head (trainable) | 526,595 |
| 合計 (trainable) | 919,875 |
| Backbone (frozen) | ~304M |

## 設定

### ハイパーパラメータ
- **画像サイズ**: 512x512
- **バッチサイズ**: 16
- **学習率**:
  - LoRA: 1e-4 (バックボーン微調整)
  - Head: 1e-3 (ヘッド学習)
- **Optimizer**: AdamW (weight_decay: 1e-2)
- **Scheduler**: CosineAnnealingLRWithWarmup (T_max=100, eta_min=1e-5)
- **Warmup**: 3 epochs
- **エポック数**: 100
- **Fold数**: 5
- **EMA**: decay 0.995

### 損失関数
- **Main Loss**: Smooth L1 Loss
- **Auxiliary Loss**: 0.1 × aux_loss (GDM/Total)

## 実装の変更点

### exp028からの主な変更
1. **LoRA統合**: peft.get_peft_model()によるLoRA適用
2. **HF Transformers使用**: TIMMからHF Dinov2Modelに変更
3. **学習率分離**: LoRAパラメータとHeadで異なる学習率
4. **最終6層のみLoRA適用**: 計算効率とタスク適応のバランス

### 技術的な考慮事項
- **パラメータ効率**: 全体の約0.3%のパラメータのみ学習
- **推論時統合**: `merge_and_unload()`でLoRAをベースモデルに統合可能
- **メモリ使用量**: 勾配計算が限定的なため、frozen backboneと同程度

## 考察

### 結果の評価
- **exp028 (CV 0.6746) と比較**: +0.71pt改善 (0.6746 → 0.6817)
- LoRAによるAttention層の微調整が有効に機能
- 全体の0.3%のパラメータ学習で精度向上を達成

### Fold間のばらつき
- Fold 1 (0.5977) が他Foldより約0.08-0.12低い
- 標準偏差0.0458と比較的高い
- データ分割の偏りまたはFold 1特有のサンプル特性が原因の可能性
