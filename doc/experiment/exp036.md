# exp036: SigLIP Backbone

## 目的
DINOv2とは異なる事前学習を持つSigLIPをバックボーンとして使用し、アンサンブル用モデルの多様性を確保する

## 設計

### アーキテクチャ
- **Backbone**: vit_large_patch16_siglip_384 (TIMM, frozen)
- **入力解像度**: 384x384
- **Head**: exp028と同一構造

### モデル構造
```
CSIROModel
├── Backbone: SigLIP ViT-Large (frozen)
├── Head: Linear layers
└── 物理制約: GDM = Clover + Green, Total = Clover + Dead + Green
```

## 設定

### ハイパーパラメータ
- **画像サイズ**: 384x384
- **バッチサイズ**: 16
- **学習率**: 1e-3 (Headのみ学習のため高めに設定)
- **Optimizer**: AdamW (weight_decay: 1e-2)
- **Scheduler**: CosineAnnealingLR (T_max=100, eta_min=1e-5)
- **Warmup**: 3 epochs
- **エポック数**: 100
- **Fold数**: 5
- **EMA**: decay 0.995

### 損失関数
- **Main Loss**: Smooth L1 Loss
- **Auxiliary Loss**: 0.1 × aux_loss (GDM/Total)

## 実装の変更点

### exp028からの主な変更
1. **Backbone変更**: DINOv2 → SigLIP
2. **画像サイズ変更**: 512x512 → 384x384 (SigLIPのネイティブサイズ)
3. **コード変更なし**: config/exp036.yamlのモデル名とimage_sizeのみ変更

### 期待される効果
- SigLIPはテキスト-画像対応学習ベースで、DINOv2とは異なる特徴表現
- アンサンブル時にモデル多様性を提供
