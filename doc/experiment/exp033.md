# exp033: DINOv3 Base + StratifiedKFold

## 目的
exp026をベースに、StratifiedKFold（State + target_bin層化）を導入し、CV間のばらつきを軽減する。

## 設定
- モデル: DINOv3 ViT-B/16 (vit_base_patch16_dinov3)
- 画像サイズ: 224
- Backbone凍結: true
- 学習率: 1e-3
- エポック数: 100
- **Fold分割: StratifiedKFold（State + target_bin層化）**

### Fold分割の変更
| 指標 | exp026 (従来) | exp033 (新規) |
|------|---------------|---------------|
| weighted_mean差 | 8.91 | 1.07 |
| weighted_mean std | 3.21 | 0.43 |
| State 0件fold | 3箇所 | 0箇所 |

## 結果
| Metric | Score |
|--------|-------|
| CV (mean) | 0.7415 |
| CV (std) | 0.0450 |
| Fold 0 | 0.7714 |
| Fold 1 | 0.6688 |
| Fold 2 | 0.7790 |
| Fold 3 | 0.7085 |
| Fold 4 | 0.7798 |
| LB | 0.59 |

## 考察
- Fold 1が他foldより約0.1低い（0.6688）
- std=0.0450は比較的高く、fold間ばらつきが大きい
- StratifiedKFold導入の効果は限定的だった可能性
- **CV-LBギャップ: 0.15** - 過学習または分布の乖離の可能性
