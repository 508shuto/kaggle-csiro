# exp035: マルチスケール Late Fusion (512全体 + 512タイル×4)

## 目的
高解像度タイル（512×512）とグローバルビュー（512×512）を組み合わせたマルチスケールアプローチで、exp028を超える精度を目指す。

## 背景
- exp028 (512全体): CV 0.6746, LB 0.63 (現時点ベスト)
- exp029 (256タイル×4): CV 0.6606 → タイルサイズが小さすぎてDINOv3の性能を活かせず
- exp030 (256タイル + MHA): CV 0.6575 → 改善せず

### 仮説
- 256×256タイルはDINOv3にとって小さすぎる（パッチ数256 vs 想定1024）
- 512×512タイルならDINOv3の想定入力サイズを維持できる
- 全体ビュー + 高解像度タイルの組み合わせで頑健な予測

## 設定
- ベース: exp028
- モデル: vit_large_patch16_dinov3.lvd1689m
- Backbone凍結: true
- 学習率: 1e-3
- エポック数: 100
- EMA: decay 0.995

### マルチスケール構成
| スケール | 入力サイズ | 出力 | 役割 |
|---------|----------|------|------|
| Global | 512×512 | 予測 (B, 3) | 全体の外観・分布パターン |
| Tile | 512×512 × 4 | 予測 (B, 4, 3) → 平均 | 高解像度の局所特徴 |

### 処理フロー
```
元画像 (2000×1000)
    │
    ├── リサイズ 512×512 → backbone → head → global_pred (B, 3)
    │
    └── リサイズ 1024×1024 → 2×2分割 → 4 × (512×512)
                                         ↓
                              backbone → head → tile_preds (B, 4, 3)
                                         ↓
                                    平均 → tile_pred (B, 3)

最終予測 = (global_pred + tile_pred) / 2
```

### Late Fusion採用理由
- 特徴統合より予測統合の方が物理的に意味がある
- 草種がタイルごとに偏っていても頑健
- 各タイルの「クローバー率」を平均 = 面積加重平均
