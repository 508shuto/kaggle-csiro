# exp035: Multiscale Late Fusion with DINOv3 Large

## 目的
マルチスケールアプローチ（グローバル + タイル分割）による高解像度情報の活用でexp028 (CV 0.6746) を超える精度を達成する

## 設計

### アーキテクチャ
- **Backbone**: vit_large_patch16_dinov3.lvd1689m (frozen)
- **入力解像度**: 1024x1024
- **マルチスケール処理**:
  - グローバルブランチ: 1024x1024 → 512x512にリサイズして処理
  - タイルブランチ: 1024x1024 → 2x2分割 (4枚の512x512タイル)
- **Late Fusion**: グローバル予測とタイル予測の平均

### モデル構造
```
CSIROModel
├── Global branch:
│   └── resize(1024→512) → backbone → head → pred_global (B, 3)
├── Tile branch:
│   └── split_2x2 → backbone × 4 → head × 4 → mean → pred_tile (B, 3)
└── Late Fusion:
    └── (pred_global + pred_tile) / 2 → pred_final (B, 5)
```

### 物理制約
- 負値クランピング
- GDM = Clover + Green
- Total = Clover + Dead + Green

## 設定

### ハイパーパラメータ
- **画像サイズ**: 1024x1024
- **バッチサイズ**: 4 (effective batch size = 16 with gradient accumulation)
- **Gradient Accumulation**: 4
- **学習率**: 1e-3 (Headのみ学習)
- **Optimizer**: AdamW
- **Scheduler**: CosineAnnealingLR (T_max=100, eta_min=1e-5)
- **エポック数**: 100
- **Fold数**: 5
- **EMA**: decay 0.995

### Augmentation
- **Mixup**: 無効 (マルチスケールアーキテクチャと非互換のため)
- **Spatial**:
  - Resize: 1024x1024
  - Horizontal Flip: p=0.5
  - Vertical Flip: p=0.5
  - Rotate: p=0.5, limit=30deg
  - Random Brightness Contrast: p=0.2
- **Pixel**:
  - Elastic Transform: p=0.2
  - Gamma Transform: p=0.2
  - Gaussian Noise: p=0.2
  - Blur: p=0.2

### 損失関数
- **Main Loss**: Weighted MAE + MSE
  - MAE weight: 0.6
  - MSE weight: 0.4
- **Auxiliary Loss**: 0.1 × (Weighted MAE + MSE for GDM/Total)

## 実装の変更点

### exp028からの主な変更
1. **高解像度入力**: 512x512 → 1024x1024
2. **マルチスケールモデル**: グローバルブランチ + タイルブランチ追加
3. **Late Fusion**: 2つのブランチの予測を平均
4. **バッチサイズ削減**: 16 → 4 (メモリ考慮)
5. **Gradient Accumulation**: 実効バッチサイズ維持のため4に設定
6. **Mixup無効化**: タイル分割との相性問題のため

### 技術的な考慮事項
- **メモリ使用量**: グローバル(1枚) + タイル(4枚) = 5回のforward pass
- **計算コスト**: exp028比で約5倍の推論時間
- **バグ修正履歴**:
  - Reshape bug: `view(4, B, 3)` → `view(B, 4, 3)` (critical)
  - Memory leak: validation時の`.detach()` 追加
  - Augmentation config: bool → float に統一

### 期待される効果
- **グローバルブランチ**: 全体的なコンテキストの把握
