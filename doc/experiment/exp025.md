# exp025: log1p廃止 + SmoothL1Loss

## 目的
EXP024をベースに、log1p変換を完全に廃止し、main lossをSmoothL1Lossに変更した実験。log空間での学習が不要かどうか、またSmoothL1LossがMSEより性能向上をもたらすかを検証する。

## 設定
- モデル: ConvNeXt Tiny (pretrained: ImageNet-22k → ImageNet-1k)
- 主要ハイパーパラメータ:
  - Loss: WeightedSmoothL1Loss（重み: `[0.1, 0.1, 0.1, 0.2, 0.5]`）
  - Aux Loss: MSE（weight: 0.1）
  - Optimizer: AdamW (lr: 1e-4, weight_decay: 1e-2)
  - Scheduler: Cosine
  - Batch size: 16 (train), 32 (valid)
  - Epochs: 100
  - Image size: 256
  - Mixup: enabled (alpha: 0.2, prob: 0.5)
- 変更点:
  - **log1p変換の完全廃止**: main target（5クラス）とaux target（2クラス）の両方でlog1p変換を削除し、rawスケールで学習・評価・推論
  - **main lossの変更**: WeightedMSELoss → WeightedSmoothL1Loss
  - **aux loss**: MSEのまま維持
  - **img2npyの廃止**: `img2npy.py` による前処理を廃止し、`input/train/` および `input/test/` のJPEG画像を直接読み込む（PILで読み込み）
  - **RMSE/MAEロギング追加**: バリデーション時に`val_rmse`、`val_mae`（全体）および`val_rmse_{class_name}`、`val_mae_{class_name}`（各クラス）をログし、モデル診断情報を充実（既存のR2スコアパターンと一貫性を保つ）
