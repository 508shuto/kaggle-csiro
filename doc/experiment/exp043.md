# exp043: LoRA + 3-fold CV Strategy

## 目的
exp038のLoRA実装とexp040のCV戦略を組み合わせ、最適なCV設定でLoRA性能を検証する。

## 設定
- モデル: facebook/dinov3-vitl16-pretrain-lvd1689m + peft LoRA
- LoRA: r=8, alpha=16, dropout=0.1, target=last 6 layers attention
- CV: 3-fold, seed 1129 (State stratification)
- 学習率: LoRA 1e-4, Head 1e-3

## ベース
- LoRA実装: exp038
- CV戦略: exp040

## 結果
| Metric | Score |
|--------|-------|
| CV | 0.7021 |
| LB | |

### Fold別スコア
| Fold | Score |
|------|-------|
| 0 | 0.6840 |
| 1 | 0.7310 |
| 2 | 0.6913 |
| Std | 0.0206 |

## 考察
- Fold間のばらつき（std: 0.0206）がやや大きい
- Fold 1が他のFoldより約4-5%高いスコアを示している
- LoRA + 3-fold CVの組み合わせでCV 0.7021を達成
