# exp030: MHA特徴統合

## 目的
補助タスク（NDVI, 高さ）の特徴をMulti Head Attentionで主タスクと統合し、精度向上を検証する。

## 背景
- exp029 (Tile処理のみ): CV TBD
- チームメンバー (Tile + MHA統合): CV 0.79775

チームメンバーの知見:
- Attention統合 > 中間特徴量共有 > Head分割

## 設定
- ベース: exp029（Tile処理）
- モデル: vit_large_patch16_dinov3.lvd1689m
- Backbone凍結: true
- 画像サイズ: 512×512
- Tile処理: 2×2グリッド + GeM Pooling
- **MHA統合**: Multi Head Attention (dim=256, heads=4)
- 学習率: 1e-3
- エポック数: 100
- Fold数: 5
