# exp047: DINOv3 + 分位回帰（Quantile Regression）

## 目的

分位回帰（Quantile Regression）を導入し、条件付き中央値を予測することで、外れ値にロバストな予測を実現する。

### 仮説

- 現状の SmoothL1Loss は条件付き期待値を予測するが、ターゲット分布に偏りがある
- 中央値予測（τ=0.5）は外れ値の影響を受けにくく、より安定した予測が期待できる
- Pinball Loss は L1 Loss に近い性質を持ちつつ、分位点予測に特化した損失関数

## 設定

- ベース: exp040（DINOv3 + Frozen backbone + 3-fold CV）
- モデル: `vit_large_patch16_dinov3.lvd1689m` (timm)
- Backbone: フリーズ（Head部分のみ学習）
- 損失関数: **PinballLoss (τ=0.5)**
- CV: 3-fold（State層化）
- Seed: 1129
- ターゲット重み: [0.1, 0.1, 0.1, 0.2, 0.5]

### Pinball Loss

```
L_τ(y, ŷ) = { τ * (y - ŷ)       if y >= ŷ
           { (τ - 1) * (y - ŷ)  if y < ŷ
```

τ=0.5 の場合、過大予測と過小予測を同等にペナルティ。
