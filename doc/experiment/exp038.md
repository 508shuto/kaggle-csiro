# exp038: HF DINOv3 Large + LoRA

## 目的
exp037のDINOv2をDINOv3に置き換え、最新のバックボーンでLoRA効果を検証

## 設定
- モデル: facebook/dinov3-vitl16-pretrain-lvd1689m (0.3B)
- バックボーン: HF AutoModel（自動解決）
- LoRA: r=8, alpha=16
- target_modules: `layer\.(1[89]|2[0-3])\.attention\.(q|k|v|o)_proj`（正規表現、最後の6レイヤー）
- 学習率: LoRA 1e-4, ヘッド 1e-3
- 画像サイズ: 512x512

### 結果の評価
- **Mean CV +2.6pt向上**: DINOv3へのアップグレードが有効
- **Std半減 (0.0458 → 0.0238)**: 安定性が大幅に改善
- **全Fold 0.68以上**: exp037で問題だったFold 1も0.6834に改善（+8.6pt）
- Fold 3が0.7500と最高スコアを記録

### DINOv3の効果
- DINOv2からDINOv3への変更だけで顕著な改善
- 特にFold間のばらつきが減少し、汎化性能が向上
- LoRA設定は同一（r=8, alpha=16）のため、純粋にバックボーンの効果
