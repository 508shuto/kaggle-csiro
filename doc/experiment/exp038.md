# exp038: HF DINOv3 Large + LoRA

## 目的

## 設定
- モデル: facebook/dinov3-vitl16-pretrain-lvd1689m (0.3B)
- バックボーン: HF AutoModel（自動解決）
- LoRA: r=8, alpha=16
- target_modules: `layer\.(1[89]|2[0-3])\.attention\.(q|k|v|o)_proj`（正規表現、最後の6レイヤー）
- 学習率: LoRA 1e-4, ヘッド 1e-3
