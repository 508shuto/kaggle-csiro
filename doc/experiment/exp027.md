# exp027: Qwen3-VL VLM Baseline

## 目的
Qwen3-VL-2B-Instructを使った回帰ベースラインの構築。VLMの視覚エンコーダから抽出した特徴量を使い、牧草量（5ターゲット）を予測する。

## 設定
- モデル: Qwen3-VL-2B-Instruct (Vision Encoder frozen)
- 主要ハイパーパラメータ:
  - Loss: WeightedSmoothL1Loss（重み: `[0.1, 0.1, 0.1, 0.2, 0.5]`）
  - Aux Loss: MSE（weight: 0.1）
  - Optimizer: AdamW (lr: 1e-4, weight_decay: 1e-2)
  - Scheduler: Cosine
  - Batch size: 8 (train), 16 (valid)
  - Gradient Accumulation: 2 (effective batch size: 16)
  - Epochs: 100
  - Image size: 384
  - Precision: bf16-mixed
  - Mixup: enabled (alpha: 0.2, prob: 0.5)
- アーキテクチャ:
  - Vision Encoder: Qwen3-VL-2B ViT (frozen)
  - Feature Dim: 1536
  - Regression Head: Linear(1536→256) + ReLU + Dropout(0.2) + Linear(256→3)
  - 物理制約: GDM = Clover + Green, Total = Clover + Dead + Green
