# exp032: Feature Caching - Head-only Training

## 目的
Vision encoder (Qwen3-VL-2B) の特徴を事前抽出してキャッシュし、学習時は regression head のみを学習することで大幅な高速化を実現する。

## ベースライン
- exp027: Qwen3-VL-2B + Frozen backbone + Regression heads

## 設定

### モデル構成
- **特徴抽出**: Qwen3-VL-2B Vision Encoder (frozen)
- **学習対象**: RegressionHeadOnly (head + aux_head のみ)
- **特徴次元**: 2048
- **Head構造**: Linear(2048→256) → ReLU → Dropout(0.2) → Linear(256→3/2)

### ハイパーパラメータ
| パラメータ | 値 |
|-----------|-----|
| batch_size (cached) | 64 (train) / 128 (valid) |
| optimizer | AdamW |
| lr | 5e-4 |
| weight_decay | 1e-2 |
| epochs | 100 |
| scheduler | cosine |

### 高速化のポイント
1. **Vision encoder forward なし**: 毎バッチの重い計算をスキップ
2. **GPU メモリ削減**: ~8GB → ~1GB
3. **DataLoader高速化**: 画像デコード不要
4. **大バッチサイズ**: メモリ余裕により batch_size 大幅増加

## 実行方法

```bash
# Step 1: 特徴抽出（1回のみ）
uv run ./src/exp032/extract_features.py --output-dir ./output/exp032/features

# Step 2: 高速学習（head のみ）
uv run ./src/exp032/train.py --folds 0 1 2 3 4 --use-cache --feature-dir ./output/exp032/features
```

## 考察

### メリット
- 学習時間 80-90% 削減
