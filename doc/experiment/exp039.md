# exp039: Multiscale Late Fusion + LoRA

## 目的
exp035 (Multiscale Late Fusion, CV 0.6948) と exp038 (LoRA, CV 0.7073) を組み合わせ、両アプローチのメリットを統合して精度向上を目指す。

## 設計

### アーキテクチャ
```
CSIROModel
├── Backbone: HF DINOv3 Large + LoRA (r=8, alpha=16)
│   └── LoRA適用レイヤー: 18-23 (最後の6層)
│
├── Global Branch:
│   └── resize(1024→512) → backbone → head → pred_global (B, 3)
│
├── Tile Branch:
│   └── split_2x2 → backbone × 4 → head × 4 → mean → pred_tile (B, 3)
│
└── Late Fusion:
    └── (pred_global + pred_tile) / 2 → pred_final (B, 5)
```

### LoRA設定
| パラメータ | 値 |
|-----------|-----|
| r (rank) | 8 |
| alpha | 16 |
| dropout | 0.1 |
| target_modules | `layer\.(1[89]\|2[0-3])\.attention\.(q\|k\|v\|o)_proj` |

## 設定

### ハイパーパラメータ
- **画像サイズ**: 1024x1024
- **バッチサイズ**: 4 (gradient accumulation: 4, effective: 16)
- **学習率**:
  - LoRA: 1e-4
  - Head: 1e-3
- **Optimizer**: AdamW (weight_decay: 1e-2)
- **Scheduler**: CosineAnnealingLR with warmup
- **Warmup**: 3 epochs
- **エポック数**: 100
- **Fold数**: 5
- **EMA**: decay 0.995
- **Mixup**: 無効（タイル分割と非互換）

### 損失関数
- **Main Loss**: Smooth L1 Loss
- **Auxiliary Loss**: 0.1 × aux_loss

## 実装の変更点

### exp038からの主な変更
1. **入力解像度**: 512x512 → 1024x1024
2. **Multiscale処理**: Global branch + Tile branch追加
3. **Late Fusion**: 両ブランチの予測を平均
4. **バッチサイズ**: 16 → 4 (メモリ考慮)
5. **Mixup無効化**: タイル分割との相性問題

### exp035からの主な変更
1. **Backbone**: TIMM → HF Transformers
2. **LoRA追加**: Frozen → LoRA fine-tuning
3. **学習率分離**: LoRAとHeadで異なる学習率
