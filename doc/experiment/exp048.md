# exp048: Qwen3-VL-2B AutoModel Feature Extraction

## 目的
Qwen3-VL-2BをAutoModelから使用して特徴量抽出し、回帰を行う。exp045のAutoModel版。

## 設定
- モデル: Qwen/Qwen3-VL-2B-Instruct (AutoModel)
- Hidden size: 1536
- 学習戦略: Encoder frozen + Head学習
- Head: MLP (1536 → 512 → 3)
- CV: 3-fold, State stratification
- Loss: WeightedSmoothL1Loss
- lr: 1e-3
- batch_size: 16
- epochs: 30

## ベース
