# Requirements

## 目的

DINOv3ベースのモデルで**分位回帰(Quantile Regression)** を導入し、予測性能を向上させる。

### 背景

- 現状（exp044）: SmoothL1Loss / WeightedSmoothL1Loss で条件付き期待値（平均）を予測
- 課題: 外れ値に敏感、分布の偏りに弱い
- 分位回帰の利点:
  - 中央値（τ=0.5）予測は外れ値に対してロバスト
  - 複数分位点予測で予測不確実性を表現可能

## 変更/追加する機能

### 1. Pinball Loss（Quantile Loss）の実装

```python
L_τ(y, ŷ) = max(τ * (y - ŷ), (τ - 1) * (y - ŷ))
```

- τ = 0.5（中央値）をデフォルトとする
- 将来的に複数分位点（τ = 0.1, 0.5, 0.9）への拡張を考慮

### 2. モデル出力の調整

- 出力構造は既存（5ターゲット）を維持
- 物理制約（Clover + Green = GDM）も維持

### 3. 評価・推論

- 評価指標は既存のWeightedR2Scoreを維持（コンペ評価指標に合わせる）
- 推論時は中央値予測をそのまま使用

## 制約・前提条件

- ベース: exp044（DINOv3 + LoRA + 3-fold CV）
- 学習設定: exp044の設定を踏襲（lr, scheduler, batch_size等）
- CVストラテジー: 3-fold（exp040で最適化済み）
- ターゲット重み: [0.1, 0.1, 0.1, 0.2, 0.5]（既存維持）
